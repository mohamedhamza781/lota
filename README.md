# كيان — لوحة إدارة برنامج الولاء

سكافولد أولي مبني على React + MUI لإدارة نظام ولاء المطعم الذكي، بناءً على وثيقة المتطلبات الوظيفية وغير الوظيفية.

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`.

## الهوية البصرية

- **الاتجاه**: RTL كامل (عبر `stylis-plugin-rtl` + `@emotion/cache`)، مطبّق من الأساس وليس إضافة لاحقة (يلبي NFR-UX-02).
- **الخطوط**: Noto Kufi Arabic للعناوين، IBM Plex Sans Arabic للنصوص، IBM Plex Mono لكل ما هو "معدود" (نقاط، أرقام، معرّفات) — يمنحها طابع دفتر حسابات.
- **اللوحة اللونية**: أبيض وأسود فقط (بدون أي لون) — خلفية بلون "ورق" دافئ (#FAFAF7) مع نسيج حبيبي خفيف يحاكي الورق المقوى، وحبر أسود (#0A0A09) للنص والعناصر. الشريط الجانبي أسود صلب مقابل الكانفاس الأبيض كعنصر تباين رئيسي.
- **تشفير الحالة بدون لون**: بما أنه لا يوجد أحمر/أخضر، كل حالة (فئة العميل، الشريحة، التنبيهات) تُقرأ عبر "كثافة الحبر": حلقة فارغة ← متقطعة ← ممتلئة ← ممتلئة بحلقة مزدوجة. هذا يجعل الواجهة مقروءة لذوي عمى الألوان كأثر جانبي.
- **العلامة (Entity Mark)**: معيّن (diamond) بخط كامل، نصفه مملوء بالحبر بالكامل — ترجمة بصرية لمعنى "كيان": شيء في طور التكوّن، نصفه ما زال مجرد خط، ونصفه اكتسب حضورًا كاملاً. نفس منطق "حبر أو لا حبر" المستخدم في شارات الفئة، لكن مرفوعًا إلى مستوى العلامة التجارية نفسها — تتكرر كعنصر ربط بصري في الشريط الجانبي، الشريط العلوي، وعناوين الأقسام.
- **بطاقات المؤشرات (KPI)**: حافة مثقّبة تحاكي إيصال الكاشير، مع ترقيم دفتري (٠١، ٠٢...) بجانب كل عنوان — يعزز فكرة أن كل رقم هو "قيد" في دفتر حسابات وليس مجرد إحصائية.

## هيكل المشروع

```
src/
  theme/          # tokens + RTL cache
  layouts/        # DashboardLayout (شريط جانبي + شريط علوي)
  components/     # TierBadge, SegmentChip, StatCard
  pages/          # Dashboard, Customers, ComingSoon (بقية الشاشات)
  mock/           # بيانات تجريبية بشكل الكيانات الفعلية (customers, kpis, alerts)
```

## الشاشات المُنجزة

- **نظرة عامة (Dashboard)**: KPIs، تنبيهات استباقية (FR-DSH-01, FR-DSH-03)
- **العملاء (Customers)**: قائمة، بحث، فلترة حسب الشريحة، شارات الفئة (FR-CUS-02, FR-CUS-04)

## الشاشات القادمة (Placeholder حاليًا)

النقاط، الكوبونات، الإشعارات، الفروع — كل مسار جاهز في `App.jsx` وينتظر بناء الصفحة الفعلية.

## ملاحظات تقنية

- لا يوجد اتصال بـ API فعلي بعد؛ البيانات في `src/mock/data.js` بنفس شكل الكيانات المتوقعة من الباك-إند لتسهيل الاستبدال لاحقًا بـ React Query.
- الألوان والخطوط مركزية في `src/theme/theme.js` (`tokens`) — أي تعديل هوية بصرية يمر من هناك فقط.
